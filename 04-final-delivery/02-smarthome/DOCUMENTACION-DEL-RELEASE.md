## GitHub Release

Copiar/adaptar [la descripción del Release](RELEASE-NOTES-PARA-COPIAR.md) y enlazar a la carpeta institucional después de fusionar el PR. El Release necesita ZIP de código de los repositorios aprobados, historial y SHA-256 reales. Los documentos preparados pueden descargarse como ZIP auxiliar, pero **no reemplazan** el registro institucional en la carpeta.

**Control de estado:** estos archivos describen el trabajo documentado. La integración de las ramas, pruebas Android físicas, corrección CI web y tags finales todavía requieren aceptación y evidencia.
